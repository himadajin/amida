# あみだくじ SPA 仕様書

## 目的

あみだくじを作成し、参加者が結果に到達するまでの経路を1人ずつ確認できるシングルページアプリケーションを作成する。

初版では人数を5人に固定し、入力、生成、経路表示、結果確認までを1画面で完結させる。内部ロジックは将来的に人数や横線数を可変にできるように設計する。

## 技術スタック

- TypeScript
- Vite
- React
- Tailwind CSS
- Vitest
- ESLint
- Prettier

## 設計方針

- 不要な処理や抽象化を避け、なるべく簡潔に実装する。
- あみだくじ生成、経路計算、結果割り当ては純粋関数として実装し、React UI から分離する。
- テストしやすい構造を優先する。
- UI は状態と計算結果を表示する責務に寄せる。
- 初版では仕様を絞り、後から人数、横線数、表示演出を拡張できる余地を残す。

## 初版スコープ

### 対象機能

- 参加者名を5人分入力できる。
- 結果名を5件分入力できる。
- 初期値として参加者名 `A`、`B`、`C`、`D`、`E` を表示する。
- 初期値として結果名 `1`、`2`、`3`、`4`、`5` を表示する。
- ボタン操作であみだくじを生成できる。
- 生成されたあみだくじを画面に表示できる。
- 参加者を1人ずつ選び、経路をたどる演出を表示できる。
- 経路表示後、その参加者の結果を表示できる。
- 全参加者の結果を最終的に確認できる。
- 同じ縦軸を一直線に進むだけの参加者が出ないようにする。

### 初版では扱わない機能

- 参加者数の UI 上での変更
- 横線数の UI 上での変更
- あみだくじの保存
- 結果の履歴管理
- 画像としてのエクスポート
- 複数ページ構成

## あみだくじ仕様

### 基本仕様

- 初版の縦軸数は5本固定とする。
- 内部ロジックでは `participantCount` を受け取り、将来的に縦軸数を可変にできるようにする。
- 横線は隣接する縦軸同士だけを接続する。
- 横線数は初版では8本固定とする。
- 生成される横線は、上から下へ順序を持つ。
- 各横線は `row` と `leftIndex` で表す。
  - `row`: 横線の高さ方向の位置
  - `leftIndex`: 左側の縦軸インデックス
- 5人の場合、`leftIndex` は `0` から `3` の範囲とする。

### 横線の制約

- 同じ `row` に同じ `leftIndex` の横線を複数配置しない。
- 同じ `row` に隣接して重なる横線を配置しない。
  - 例: `leftIndex = 1` の横線と `leftIndex = 2` の横線は同じ `row` に置かない。
- すべての縦軸は、最低1回は横線に接続される。
  - 左端または右端の縦軸も対象とする。
  - 参加者が一度も横移動せずに結果へ到達する状態を避ける。
- あみだくじの結果は必ず重複しない。
  - 参加者5人は、それぞれ異なる結果に到達する。

### 経路計算

- 参加者は上から下へ進む。
- 現在の縦軸に対して、同じ `row` に左または右へ接続する横線がある場合、その横線をたどって隣の縦軸へ移動する。
- 横線をたどった後、次の `row` へ進む。
- 最下部に到達した縦軸インデックスを結果インデックスとする。

## アプリケーション状態

アプリケーション状態は以下を基本とする。

### `editing`

- 参加者名と結果名を編集できる。
- あみだくじは未生成、または編集内容と一致しないため結果表示しない。
- 「あみだを作る」ボタンを表示する。

### `drawn`

- あみだくじ生成済みの状態。
- 参加者名と結果名は表示する。
- 参加者ごとの経路表示を開始できる。
- 「もう一度作る」ボタンを表示する。
- 「入力を編集する」操作で `editing` に戻れる。

### `revealing`

- 参加者1人分の経路を表示している状態。
- 対象の参加者の経路を強調表示する。
- 演出中は同時に別の参加者の経路表示を開始しない。
- 経路表示が完了したら、その参加者の結果を表示する。

### `completed`

- 全参加者の結果が表示された状態。
- 結果一覧を確認できる。
- 「もう一度作る」ボタンで同じ入力から新しいあみだくじを生成できる。
- 「入力を編集する」操作で `editing` に戻れる。

## UI 仕様

### 全体

- シングルページで完結する。
- ライトモードのみ対応する。
- Tailwind CSS のデフォルトカラーパレットを使用する。
- モダンでシンプルな見た目にする。
- 装飾よりも、入力、生成、経路確認の分かりやすさを優先する。

### 画面構成

- ヘッダー
  - アプリ名を表示する。
  - 短い説明文を表示する。
- 入力エリア
  - 参加者名5件の入力欄を表示する。
  - 結果名5件の入力欄を表示する。
- 操作エリア
  - 「あみだを作る」ボタンを表示する。
  - 生成後は「もう一度作る」ボタンを表示する。
  - 生成後は「入力を編集する」ボタンを表示する。
- あみだ表示エリア
  - 上部に参加者名を表示する。
  - 中央にあみだくじを表示する。
  - 下部に結果名を表示する。
- 結果エリア
  - 経路表示済みの参加者と結果の対応を表示する。
  - 全員分の表示が終わったら、最終結果一覧として表示する。

### あみだ表示

- SVG で描画する。
- 縦線、横線、選択中の経路を描画する。
- 選択中の経路は通常線より目立つ色と太さで表示する。
- 経路表示済みの参加者は、結果が分かる状態にする。
- まだ経路表示していない参加者の結果は隠す。

### 経路表示操作

- あみだ生成後、参加者ごとに「たどる」操作を行える。
- 参加者を1人選ぶと、その参加者の経路が上から下へ順に表示される。
- 経路表示が完了するまで、その参加者の結果は表示しない。
- 経路表示が完了したら、対応する結果を表示する。
- すでに結果表示済みの参加者は再度たどれるが、結果は変わらない。

## データ設計

### 型の基本方針

```ts
type LadderLine = {
  row: number;
  leftIndex: number;
};

type Ladder = {
  participantCount: number;
  lineCount: number;
  lines: LadderLine[];
};

type Assignment = {
  participantIndex: number;
  resultIndex: number;
};

type PathStep =
  | {
      type: 'vertical';
      fromRow: number;
      toRow: number;
      index: number;
    }
  | {
      type: 'horizontal';
      row: number;
      fromIndex: number;
      toIndex: number;
    };
```

### 想定する純粋関数

```ts
function generateLadder(
  participantCount: number,
  options: { lineCount: number },
  random: () => number,
): Ladder;

function traceLadder(ladder: Ladder, startIndex: number): number;

function getPathSteps(ladder: Ladder, startIndex: number): PathStep[];

function resolveAssignments(ladder: Ladder): Assignment[];

function getTouchedVerticals(ladder: Ladder): Set<number>;

function validateLadder(ladder: Ladder): boolean;
```

## バリデーション

- 参加者名が空の場合はエラーを表示する。
- 結果名が空の場合はエラーを表示する。
- 参加者名の重複は初版では許可する。
- 結果名の重複は初版では許可する。
- エラーがある場合は、あみだくじを生成できない。

## テスト方針

### ロジックテスト

- 指定した人数と横線数であみだくじを生成できる。
- 横線が隣接する縦軸同士だけを接続する。
- 同じ `row` に重なる横線が生成されない。
- すべての縦軸が最低1回は横線に接続される。
- `traceLadder` が正しい結果インデックスを返す。
- `resolveAssignments` の結果に重複がない。
- `getPathSteps` が縦移動と横移動の順序を返す。
- 乱数関数を差し替えることで、生成結果を決定的にテストできる。

### UI テスト

- 初期表示で参加者名と結果名の初期値が表示される。
- 空欄がある場合、あみだくじを生成できない。
- 「あみだを作る」であみだくじが表示される。
- 参加者を選ぶと経路表示が開始される。
- 経路表示完了後に結果が表示される。
- 全員分の経路表示後、最終結果一覧が表示される。

## 実装メモ

- 生成ロジックは `src/lib/ladder.ts` のような UI 非依存モジュールに配置する。
- React コンポーネントは `src/App.tsx` を起点に、必要に応じて小さく分割する。
- SVG 座標計算も可能な限り関数化する。
- アニメーションは初版では CSS transition または React state とタイマーで実装する。
- テストで扱いやすくするため、乱数関数は `generateLadder` の引数として注入する。
